# Mac MIF Viewer

在 Mac 上浏览多重免疫荧光（mIF）全切片。支持 MRXS 原生预览、独立通道调色、ROI 测量，以及带标尺的图像导出。切片的查看、编辑和导出都在本机完成。

**[下载 Mac 版](https://github.com/xuxiaoooo/MacMIFViewer/releases/latest)** · Apple Silicon · macOS 14+

## 功能

| 功能 | 操作 |
| --- | --- |
| 全片浏览 | 滚轮或触控板缩放，拖拽平移，点击导航缩略图跳到目标位置。 |
| 多通道显示 | 显示、隐藏或单显各通道，一键返回 Merge。支持 RGB 拉条、快捷色样、灰度、热度色图，以及独立黑点、白点和 Gamma。 |
| ROI 与测量 | 保存多个矩形、多边形或测距线。可重命名、定位、删除或拖动顶点，查看面积和距离。 |
| 标尺与校准 | 标尺随缩放更新，可输入 X、Y 像素尺寸。没有物理尺寸时以像素显示。 |
| 图像导出 | 将选中的 ROI 导出为 **PNG、JPEG 或 TIFF**。开启标尺时可随图导出，每次另附 ROI 坐标 JSON 和 CSV。 |
| 自动恢复 | 本地保存每张切片的 ROI、校准和通道显示设置，重开同一文件时恢复。 |

## 快速开始

1. 下载 arm64 ZIP，解压并打开 `Mac MIF Viewer.app`。启动时会显示六通道演示。
2. 点击 **打开切片…**，选择 MRXS 或 OME-TIFF，也可以一次选择同一位置、分辨率和焦平面的多个灰度 TIFF。
3. 点击右侧通道名称调色。用顶部 **矩形** 或 **多边形** 工具画出 ROI，多边形按回车完成。
4. 在 **ROI 与测量** 选中要导出的区域，按需开启 **标尺**，然后选择 **导出 ROI** 中的图像格式。

## 支持的文件

| 格式 | 支持范围 |
| --- | --- |
| **MRXS** | 支持 8-bit IPP JPEG 规则网格变体。将 `.mrxs` 与同名配套目录放在同一位置，打开 `.mrxs` 即可。文件标尺显示为待核验，提供渲染预览导出。 |
| **OME-TIFF** | 单文件、单图像、单 Z/T，支持 1–8 个独立 8-bit 或 16-bit 灰度通道及 SubIFD 金字塔。 |
| **分通道 TIFF** | 每个 TIFF 对应一个灰度通道，按自然文件名顺序载入。 |

同位深的 TIFF 通道可导出独立通道的 **Raw OME-TIFF**。PNG 和 JPEG 导出上限为 1200 万像素、单边 8192 px，较大的 ROI 可用分块 TIFF。多边形导出图像为外接矩形，顶点记录在附带文件中。
